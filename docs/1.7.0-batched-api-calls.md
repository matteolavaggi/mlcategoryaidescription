# Version 1.7.0 - Batched API Calls Implementation Plan

## Overview

Reduce API calls by 75% by sending all fields for a category in a single request instead of one request per field.

### Current Behavior (v1.6.x)
```
Category "Shoes" + Language "IT":
  → API call 1: description
  → API call 2: meta_title
  → API call 3: meta_description  
  → API call 4: meta_keywords
  = 4 API calls per category/language
```

### New Behavior (v1.7.0)
```
Category "Shoes" + Language "IT":
  → API call 1: all 4 fields in one JSON response
  = 1 API call per category/language
```

### Impact

| Metric | Before | After | Improvement |
|--------|--------|-------|-------------|
| API calls per category/lang | 4 | 1 | **-75%** |
| Job with 100 categories × 3 langs | 1,200 calls | 300 calls | **-75%** |
| API costs | $X | $X/4 | **-75%** |

### API Limits Reference

| API | Batch Limit | Notes |
|-----|-------------|-------|
| Google Translate v2 | 128 segments per request | Each field = 1 segment. 4 fields/category = 32 categories max per call |
| OpenAI | No segment limit | Limited by token context window |

### New Implementation

The key insight: we keep using the per-field prompt templates from DB, but combine all resolved prompts into a single OpenAI request that returns structured JSON.

```php
/**
 * Generate all fields for a category in a single API call
 * Uses existing prompt templates from DB, combines them into structured JSON request
 *
 * @param int $idCategory
 * @param int $idLang
 * @param array $fields ['description', 'meta_title', 'meta_description', 'meta_keywords']
 * @param string $writeMode
 *
 * @return array ['success' => bool, 'results' => [...], 'error' => string]
 */
public function generateCategoryBatch($idCategory, $idLang, array $fields, $writeMode = 'fill_missing')
{
    $category = new Category((int) $idCategory, (int) $idLang);
    $placeholder = new MlCategoryAiPlaceholder($idCategory, $idLang, $this->idShop);
    
    // Build combined prompt using existing templates
    $fieldPrompts = [];
    $skippedFields = [];
    
    foreach ($fields as $fieldType) {
        // link_rewrite is generated locally from meta_title, not by AI
        if ($fieldType === Mlcategoryaidescription::FIELD_LINK_REWRITE) {
            continue;
        }
        
        // Skip if fill_missing and field has content
        if ($writeMode === 'fill_missing') {
            $existing = $this->getFieldValue($category, $fieldType);
            if (!empty(trim(strip_tags($existing)))) {
                $skippedFields[] = $fieldType;
                continue;
            }
        }
        
        // Get the prompt template from DB (respects user customizations)
        $template = $this->getPromptTemplate($fieldType, $idLang);
        $resolvedPrompt = $placeholder->resolve($template);
        $fieldPrompts[$fieldType] = $resolvedPrompt;
    }
    
    if (empty($fieldPrompts)) {
        return ['success' => true, 'skipped' => true, 'results' => [], 'skipped_fields' => $skippedFields];
    }
    
    // Build the combined JSON request
    $combinedPrompt = $this->buildCombinedJsonPrompt($fieldPrompts, $idLang);
    
    // Use response_format for guaranteed JSON
    $response = $this->client->generateJson($combinedPrompt);
    
    if ($response === false) {
        return ['success' => false, 'error' => $this->client->getLastError()];
    }
    
    return $this->parseAndSaveResults($response, $category, $fieldPrompts, $idLang, $fields);
}

/**
 * Build combined prompt that embeds all field prompts and requests JSON output
 */
protected function buildCombinedJsonPrompt(array $fieldPrompts, $idLang)
{
    $languageName = Language::getNameById($idLang);
    
    $prompt = "Generate SEO content in {$languageName}. For each field below, follow the specific instructions provided.\n\n";
    
    foreach ($fieldPrompts as $fieldType => $fieldPrompt) {
        $prompt .= "=== FIELD: {$fieldType} ===\n";
        $prompt .= $fieldPrompt . "\n\n";
    }
    
    $prompt .= "RESPONSE FORMAT:\n";
    $prompt .= "Return a JSON object with these exact keys: " . json_encode(array_keys($fieldPrompts)) . "\n";
    $prompt .= "Each value should be the generated content for that field.\n";
    $prompt .= "For 'description': use HTML tags (<p>, <h2>, <strong>, <ul>, <li>).\n";
    $prompt .= "For other fields: plain text only, no HTML.\n";
    
    return $prompt;
}

/**
 * Parse JSON response and save all fields to category
 * Atomic: if any field is missing, fail entirely without saving anything
 *
 * @param array $jsonData Parsed JSON from OpenAI
 * @param Category $category
 * @param array $fieldPrompts Fields that were requested (excludes link_rewrite)
 * @param int $idLang
 * @param array $originalFields Original field list (may include link_rewrite)
 */
protected function parseAndSaveResults($jsonData, $category, $fieldPrompts, $idLang, $originalFields = [])
{
    // First, validate all required fields are present
    foreach (array_keys($fieldPrompts) as $fieldType) {
        if (!isset($jsonData[$fieldType])) {
            MlCategoryAiLogger::error("Missing field in JSON response: {$fieldType}", [
                'category_id' => $category->id,
                'lang_id' => $idLang,
                'received_keys' => array_keys($jsonData),
            ]);
            return [
                'success' => false,
                'error' => "Missing field in JSON response: {$fieldType}",
            ];
        }
    }
    
    // All fields present, now save them
    $results = [];
    foreach (array_keys($fieldPrompts) as $fieldType) {
        $content = $this->cleanContent($jsonData[$fieldType], $fieldType);
        $updateResult = $this->updateCategoryField($category, $fieldType, $content, $idLang);
        $results[$fieldType] = $updateResult ? 'success' : 'failed';
    }
    
    // Generate link_rewrite from meta_title if it was in original request
    // (link_rewrite is not AI-generated, it's derived from meta_title)
    if (in_array(Mlcategoryaidescription::FIELD_LINK_REWRITE, $originalFields)) {
        $this->generateLinkRewriteFromMetaTitle($category->id, $idLang, 'overwrite');
        $results[Mlcategoryaidescription::FIELD_LINK_REWRITE] = 'success';
    }
    
    return [
        'success' => true,
        'results' => $results,
        'tokens' => $this->client->getLastTokensUsed(),
    ];
}
```

### MlCategoryAiClient Changes

Add `generateJson()` method that uses OpenAI's native `response_format`:

```php
/**
 * Generate content with guaranteed JSON response format
 *
 * @param string $prompt
 * @param string $systemMessage
 *
 * @return array|false Parsed JSON array or false on error
 */
public function generateJson($prompt, $systemMessage = '')
{
    $this->lastError = '';
    
    if (empty($systemMessage)) {
        $systemMessage = 'You are an SEO expert. Generate content as requested.';
    }
    
    $messages = [
        ['role' => 'system', 'content' => $systemMessage],
        ['role' => 'user', 'content' => $prompt],
    ];
    
    $requestData = [
        'model' => $this->model,
        'messages' => $messages,
        'response_format' => ['type' => 'json_object'],  // Guarantees JSON output
    ];
    
    // Add token limit
    if ($this->maxTokens > 0) {
        $tokenParam = $this->getTokenLimitParamName();
        $requestData[$tokenParam] = $this->maxTokens;
    }
    
    $url = $this->buildUrl();
    $response = $this->sendRequest($url, $requestData);
    
    if ($response === false) {
        return false;
    }
    
    $content = $this->parseResponse($response);
    if ($content === false) {
        return false;
    }
    
    // Parse JSON (guaranteed valid by response_format)
    $data = json_decode($content, true);
    if (json_last_error() !== JSON_ERROR_NONE) {
        $this->lastError = 'JSON parse error: ' . json_last_error_msg();
        MlCategoryAiLogger::error($this->lastError, ['content' => substr($content, 0, 500)]);
        return false;
    }
    
    return $data;
}
```

### Error Handling

- **Category fails entirely if API call fails** - no partial updates
- **If JSON parsing fails** - log error, mark category as failed, do NOT update any fields
- **Token limit exceeded** - log error with category ID, fail the category
- **No fallback to per-field** - simpler logic, category is success or fail

## Phase 2: Google Translate Batching

**Priority:** HIGH (complements OpenAI batching)

### Current State

`MlCategoryAiTranslator::translateBatch()` already exists and supports multiple texts. 
However, the job queue still iterates per-field, not using the batch capability efficiently.

### Changes Needed

Modify `MlCategoryAiGenerator` to translate all fields for a category in one call:

```php
/**
 * Translate all fields for a category in a single API call
 *
 * @param int $idCategory
 * @param int $idTargetLang
 * @param array $fields Fields to translate
 * @param int $idSourceLang
 * @param string $writeMode
 *
 * @return array Result with per-field status
 */
public function translateCategoryBatch($idCategory, $idTargetLang, array $fields, $idSourceLang, $writeMode = 'fill_missing')
{
    $result = [
        'success' => false,
        'results' => [],
        'chars_translated' => 0,
        'skipped' => false,
    ];
    
    $sourceCategory = new Category((int) $idCategory, (int) $idSourceLang);
    $targetCategory = new Category((int) $idCategory, (int) $idTargetLang);
    
    // Collect texts to translate (skip fields with existing content in fill_missing mode)
    $textsToTranslate = [];
    $skippedFields = [];
    
    foreach ($fields as $fieldType) {
        if ($fieldType === Mlcategoryaidescription::FIELD_LINK_REWRITE) {
            continue;  // Generated locally, not translated
        }
        
        if ($writeMode === 'fill_missing') {
            $existing = $this->getFieldValue($targetCategory, $fieldType);
            if (!empty(trim(strip_tags($existing)))) {
                $skippedFields[] = $fieldType;
                continue;
            }
        }
        
        $sourceText = $this->getFieldValue($sourceCategory, $fieldType);
        if (!empty(trim(strip_tags($sourceText)))) {
            $textsToTranslate[$fieldType] = $sourceText;
        }
    }
    
    if (empty($textsToTranslate)) {
        $result['success'] = true;
        $result['skipped'] = true;
        return $result;
    }
    
    // Get ISO codes
    $sourceIso = Language::getIsoById($idSourceLang);
    $targetIso = Language::getIsoById($idTargetLang);
    
    // Single API call for all fields
    $translator = MlCategoryAiTranslator::createFromConfig($this->module);
    $translations = $translator->translateBatch(
        array_values($textsToTranslate),
        $sourceIso,
        $targetIso,
        'html'  // Use HTML format, then strip from non-HTML fields after
    );
    
    if ($translations === false) {
        $result['error'] = $translator->getLastError();
        return $result;  // Entire category fails
    }
    
    // Map translations back to fields and save
    $fieldKeys = array_keys($textsToTranslate);
    foreach ($translations as $index => $translatedText) {
        $fieldType = $fieldKeys[$index];
        
        // Strip HTML from non-description fields (purify after translation)
        if ($fieldType !== Mlcategoryaidescription::FIELD_DESCRIPTION) {
            $translatedText = strip_tags($translatedText);
            $translatedText = html_entity_decode($translatedText, ENT_QUOTES, 'UTF-8');
        }
        
        $this->updateCategoryField($targetCategory, $fieldType, $translatedText, $idTargetLang);
        $result['results'][$fieldType] = 'success';
    }
    
    $result['success'] = true;
    $result['chars_translated'] = $translator->getLastCharactersTranslated();
    
    return $result;
}
```

### HTML Handling Strategy

Google Translate preserves HTML when `format: 'html'` is used. After translation:

1. **description** - Keep HTML as-is
2. **meta_title, meta_description, meta_keywords** - Strip HTML tags and decode entities

```php
// After translation, for non-HTML fields:
$translatedText = strip_tags($translatedText);
$translatedText = html_entity_decode($translatedText, ENT_QUOTES, 'UTF-8');
```

## Phase 3: Job Queue Refactoring

### Current Item Structure (per-field)

```php
$items = [
    ['id_category' => 1, 'id_lang' => 1, 'field_type' => 'description'],
    ['id_category' => 1, 'id_lang' => 1, 'field_type' => 'meta_title'],
    // ... 4 items per category/lang
];
```

### New Item Structure (per-category)

```php
$items = [
    ['id_category' => 1, 'id_lang' => 1, 'fields' => ['description', 'meta_title', ...]],
    ['id_category' => 1, 'id_lang' => 2, 'fields' => ['description', 'meta_title', ...]],
    // ... 1 item per category/lang
];
```

### Counting Logic Change

No `batch_mode` column needed. Change how `total_items` is calculated:

**Before (v1.6.x):**
```php
$totalItems = count($categoryIds) * count($languageIds) * count($fields);
```

**After (v1.7.0):**
```php
$totalItems = count($categoryIds) * count($languageIds);  // Categories, not fields
```

### Changes to `createJob()`

```php
public function createJob($categoryIds, $languageIds, $fieldsToGenerate, $writeMode = 'fill_missing', $gtOptions = [])
{
    $useGoogleTranslate = !empty($gtOptions['use_google_translate']);
    $primaryLanguageId = isset($gtOptions['primary_language_id']) ? (int) $gtOptions['primary_language_id'] : null;
    $translateLanguageIds = isset($gtOptions['translate_language_ids']) ? $gtOptions['translate_language_ids'] : [];

    // NEW: Count by category/language pairs, NOT by fields
    if ($useGoogleTranslate && $primaryLanguageId) {
        // Phase 1: categories × 1 primary language
        $openAiItems = count($categoryIds) * 1;
        // Phase 2: categories × target languages
        $gtItems = count($categoryIds) * count($translateLanguageIds);
        $totalItems = $openAiItems + $gtItems;
    } else {
        // Simple: categories × languages
        $totalItems = count($categoryIds) * count($languageIds);
    }
    
    // ... rest of job creation
}
```

### Changes to `buildItemsList()`

```php
protected function buildItemsList($job)
{
    $items = [];
    $fields = $job['fields_to_generate'];
    
    if (!empty($job['use_google_translate']) && !empty($job['primary_language_id'])) {
        return $this->buildItemsListGoogleTranslate($job);
    }
    
    // NEW: One item per category/language (fields bundled)
    foreach ($job['category_ids'] as $idCategory) {
        foreach ($job['language_ids'] as $idLang) {
            $items[] = [
                'id_category' => (int) $idCategory,
                'id_lang' => (int) $idLang,
                'fields' => $fields,  // All fields in one item
                'source' => 'openai',
            ];
        }
    }
    
    return $items;
}

protected function buildItemsListGoogleTranslate($job)
{
    $items = [];
    $primaryLangId = (int) $job['primary_language_id'];
    $translateLangIds = $job['translate_language_ids'] ?: [];
    $fields = $job['fields_to_generate'];
    $phase = isset($job['phase']) ? $job['phase'] : 'openai';
    
    if ($phase === 'openai') {
        // Phase 1: OpenAI for primary language (one item per category)
        foreach ($job['category_ids'] as $idCategory) {
            $items[] = [
                'id_category' => (int) $idCategory,
                'id_lang' => $primaryLangId,
                'fields' => $fields,
                'source' => 'openai',
            ];
        }
    } elseif ($phase === 'translate') {
        // Phase 2: Google Translate for other languages (one item per category/lang)
        foreach ($translateLangIds as $targetLangId) {
            foreach ($job['category_ids'] as $idCategory) {
                $items[] = [
                    'id_category' => (int) $idCategory,
                    'id_lang' => (int) $targetLangId,
                    'fields' => $fields,
                    'source' => 'google_translate',
                    'source_lang_id' => $primaryLangId,
                ];
            }
        }
    }
    
    return $items;
}
```

### Changes to Item Processing

Each item now represents a full category. Update `processSequentialBatch()` and `processParallelBatch()` to call the new batch methods.

The current code processes items one at a time in a loop. Replace the per-field logic with batch calls:

```php
// In processSequentialBatch() - replace per-item processing logic

foreach ($batchItems as $item) {
    $generator = new MlCategoryAiGenerator($module, $this->idShop);
    
    if ($item['source'] === 'openai') {
        // NEW: Single call for all fields
        $result = $generator->generateCategoryBatch(
            $item['id_category'],
            $item['id_lang'],
            $item['fields'],
            $job['write_mode']
        );
    } elseif ($item['source'] === 'google_translate') {
        // NEW: Single call for all fields translation
        $result = $generator->translateCategoryBatch(
            $item['id_category'],
            $item['id_lang'],
            $item['fields'],
            $item['source_lang_id'],
            $job['write_mode']
        );
        
        // Generate link_rewrite locally if included in fields
        if (in_array(Mlcategoryaidescription::FIELD_LINK_REWRITE, $item['fields'])) {
            $generator->generateLinkRewriteFromMetaTitle(
                $item['id_category'],
                $item['id_lang'],
                $job['write_mode']
            );
        }
    }
    
    // Track success/failure per category (not per field)
    if ($result['success']) {
        $processed++;
    } else {
        $failed++;
        $errors[] = "Category {$item['id_category']}: " . ($result['error'] ?? 'Unknown error');
    }
}
```

**Note**: For `processParallelBatch()`, OpenAI parallel requests remain useful. Each parallel request now generates ALL fields for ONE category, rather than one field per request. This is still faster than sequential when processing multiple categories.
