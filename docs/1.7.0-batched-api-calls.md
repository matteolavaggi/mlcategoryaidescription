# Version 1.7.0 - Batched API Calls Implementation Plan

## Overview

Reduce API calls by 75% by sending all fields for a category in a single request instead of one request per field.

### Current Behavior (v1.6.x)
```
Category "Shoes" + Language "IT":
  → API call 1: description
  → API call 2: meta_title
  → API call 3: meta_description  
  → API call 4: meta_keywords
  = 4 API calls per category/language
```

### New Behavior (v1.7.0)
```
Category "Shoes" + Language "IT":
  → API call 1: all 4 fields at once
  = 1 API call per category/language
```

### Impact

| Metric | Before | After | Improvement |
|--------|--------|-------|-------------|
| API calls per category/lang | 4 | 1 | **-75%** |
| Job with 100 categories × 3 langs | 1,200 calls | 300 calls | **-75%** |
| Estimated time (100 cat × 3 lang) | ~20 min | ~5 min | **-75%** |
| API costs | $X | $X/4 | **-75%** |

### New Implementation

```php
/**
 * Translate multiple texts in a single API call
 *
 * @param array $texts Array of texts to translate ['field_name' => 'text']
 * @param string $sourceLang Source language ISO code
 * @param string $targetLang Target language ISO code
 * @param array $formats Format per field ['description' => 'html', 'meta_title' => 'text']
 *
 * @return array Translated texts ['field_name' => 'translated_text']
 */
public function translateBatch(array $texts, $sourceLang, $targetLang, array $formats = [])
{
    // Google Translate API v2 supports array of strings natively
    $payload = [
        'q' => array_values($texts),  // ["Description...", "Meta Title", ...]
        'source' => $sourceLang,
        'target' => $targetLang,
        'format' => 'html',  // Use HTML to preserve formatting
    ];
    
    // Single API call
    $response = $this->callApi($payload);
    
    // Map results back to field names
    $keys = array_keys($texts);
    $results = [];
    foreach ($response['translations'] as $index => $translation) {
        $results[$keys[$index]] = $translation['translatedText'];
    }
    
    return $results;
}
```

**Priority:** MEDIUM (more complex, requires JSON parsing)

    $response = $this->client->chat($prompt);
    return $response['content'];

```

### New Implementation

```php
/**
 * Generate all fields for a category in a single API call
 *
 * @param Category $category
 * @param array $fields ['description', 'meta_title', 'meta_description', 'meta_keywords']
 * @param int $langId
 *
 * @return array ['description' => '...', 'meta_title' => '...', ...]
 */
public function generateCategoryContent($category, array $fields, $langId)
{
    $prompt = $this->buildBatchPrompt($category, $fields, $langId);
    
    $systemPrompt = "You are an SEO expert. Respond ONLY with valid JSON, no markdown, no explanation.";
    
    $response = $this->client->chat($prompt, $systemPrompt);
    
    // Parse JSON response
    $content = $this->parseJsonResponse($response['content']);
    
    return $content;
}

/**
 * Build prompt requesting JSON output for multiple fields
 */
protected function buildBatchPrompt($category, array $fields, $langId)
{
    $categoryName = $category->name[$langId];
    $langCode = Language::getIsoById($langId);
    
    // Build context (same as current single-field prompts)
    $context = $this->buildCategoryContext($category, $langId);
    
    // Request JSON output
    $fieldsJson = json_encode($fields);
    
    $prompt = <<<PROMPT
Generate SEO content for the category "{$categoryName}" in {$langCode} language.

Context:
{$context}

Generate the following fields and respond with ONLY a JSON object:
{$fieldsJson}

Required JSON format:
{
  "description": "HTML description (2-3 paragraphs, use <p> tags)",
  "meta_title": "SEO title (max 70 chars)",
  "meta_description": "SEO description (max 160 chars)",
  "meta_keywords": "comma-separated keywords (max 10)"
}

Respond with valid JSON only. No markdown code blocks. No explanations.
PROMPT;

    return $prompt;
}

/**
 * Parse JSON response with error handling
 */
protected function parseJsonResponse($content)
{
    // Remove markdown code blocks if present
    $content = preg_replace('/^```json?\s*/i', '', $content);
    $content = preg_replace('/\s*```$/i', '', $content);
    $content = trim($content);
    
    $data = json_decode($content, true);
    
    if (json_last_error() !== JSON_ERROR_NONE) {
        // Try to extract JSON from response
        if (preg_match('/\{[\s\S]*\}/m', $content, $matches)) {
            $data = json_decode($matches[0], true);
        }
        
        if (json_last_error() !== JSON_ERROR_NONE) {
            throw new Exception('Invalid JSON response: ' . json_last_error_msg());
        }
    }
    
    // Validate required fields
    $required = ['description', 'meta_title', 'meta_description', 'meta_keywords'];
    foreach ($required as $field) {
        if (!isset($data[$field])) {
            throw new Exception("Missing field in response: {$field}");
        }
    }
    
    return $data;
}
```

### Robust JSON Parsing Strategy

1. **Clean markdown artifacts**
   ```php
   $content = preg_replace('/^```json?\s*/i', '', $content);
   $content = preg_replace('/\s*```$/i', '', $content);
   ```

2. **Extract JSON from mixed content**
   ```php
   if (preg_match('/\{[\s\S]*\}/m', $content, $matches)) {
       $data = json_decode($matches[0], true);
   }
   ```

3. **Handle escaped characters**
   ```php
   $content = preg_replace('/[\x00-\x1F\x7F]/u', '', $content);
   ```

4. **Retry with explicit instruction on failure**
   ```php
   if ($parseError) {
       $retryPrompt = "Your previous response was not valid JSON. " .
                      "Please respond with ONLY a JSON object, no other text.";
       // Retry API call
   }
   ```

### New Item Structure

```php

    ['category' => 1, 'lang' => 1, 'fields' => ['description', 'meta_title', ...]],
    ['category' => 1, 'lang' => 2, 'fields' => ['description', 'meta_title', ...]],
    ['category' => 2, 'lang' => 1, 'fields' => ['description', 'meta_title', ...]],
    // ...

```

### Database Changes

```sql
-- Add batch_mode column to track job type

ADD COLUMN batch_mode TINYINT(1) DEFAULT 1 COMMENT '0=legacy per-field, 1=batched';
```

### Migration Strategy for Existing Jobs

```php
// In upgrade-1.7.0.php
function upgrade_module_1_7_0($module)
{
    // Add batch_mode column
    $sql = 'ALTER TABLE `' . _DB_PREFIX_ . 'mlcategoryai_job_queue` 
            ADD COLUMN `batch_mode` TINYINT(1) DEFAULT 0';
    Db::getInstance()->execute($sql);
    
    // Mark all existing jobs as legacy mode
    $sql = 'UPDATE `' . _DB_PREFIX_ . 'mlcategoryai_job_queue` 
            SET `batch_mode` = 0 
            WHERE `status` IN ("pending", "running", "paused")';
    Db::getInstance()->execute($sql);
    
    return true;
}
```

### Backwards Compatibility

```php
public function processNextBatch($jobId, $module, $batchSize)
{
    $job = $this->getJob($jobId);
    
    if ($job['batch_mode'] == 0) {
        // Legacy per-field processing
        return $this->processNextBatchLegacy($jobId, $module, $batchSize);
    }
    
    // New batched processing
    return $this->processNextBatchBatched($jobId, $module, $batchSize);
}
```
